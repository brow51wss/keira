# Host Keira brand consistency

Read BRAND-GUIDE.md before adding or restyling website sections or pages.

- Treat dist/brand.css as the canonical source for colors, responsive type, spacing, and shared UI primitives.
- Load brand.css before page-specific CSS. Use the hk- classes or existing CSS variables rather than new near-duplicate values.
- Keep page layout in its own stylesheet. Do not copy the entire home-page styles.css into new pages.
- Preserve the established Cormorant Garamond / Montserrat pairing and black, gold, cream palette.
- Preserve responsive layout, keyboard navigation, reduced-motion behavior, honest inquiry states, and source-grounded content.
- If the user explicitly changes the brand, update the shared CSS, written guide, and visual guide together.
- Verify relevant responsive sizes and interactions after material changes; keep the downloadable website archive synchronized when delivering updates.
